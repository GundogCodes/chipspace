01 / THE MAP

Storage, dressed as hardware.

This RAM-board-inspired map shows disk storage—not memory. Bigger chips mean bigger folders. It maps common contributors to System Data and other categories; it cannot reproduce Apple’s category exactly.

02 / THE NUMBERS

Measured ≠ reclaimable.

The board avoids counting nested folders twice. APFS clones, snapshots, permission gaps, and changing files still affect measurements. Free space is measured separately from folder allocation.

03 / CLEANUP

You’re at the controls.

Recognized caches and optional downloads can be reviewed for removal. Quit the owning app first. Every action requires confirmation. Unknown app data and protected system folders stay inspection-only. Trash is reversible but doesn’t immediately free space.

04 / COVERAGE

Some doors stay closed.

For a fuller scan, add Chipspace to System Settings → Privacy & Security → Full Disk Access, then quit and reopen it. Other users, custom storage locations, and redirected folders may be outside this scan. No administrator password is needed.

05 / PREVENTION

Retire what you don’t use.

Review simulator versions after Xcode updates. Remove unused AI model downloads. Check retained data before uninstalling an app. Rescan periodically: folder details show growth when two complete measurements are available.

06 / LOCAL ONLY

Your disk stays your business.

No accounts, uploads, trackers, or cloud backend. Chipspace runs on 127.0.0.1 and stores reports on this Mac. Use its chip icon in the menu bar to reopen the dashboard or quit the server.
